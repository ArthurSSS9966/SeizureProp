# Public documentation

- [Package interface](../src/seizureprop/README.md): supported inputs and exact output meanings.
- [Offline NWB workflow](offline_nwb_workflow.md): planned local import; not yet implemented.
- [Data publication policy](data_publication_policy.md): local-only material and release checks.

Proposals and proposal reviews are retained locally and excluded from Git.
Historical scientific reports, cohort protocols, source inventories and manuscript
drafts are retained locally but excluded because they may include participant
identifiers, individual outcomes or clinical mappings. They have not been deleted
or silently rewritten. General documentation does not establish clinical validity.
