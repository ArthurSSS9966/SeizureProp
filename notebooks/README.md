# Local research notebooks

The 15 historical notebooks remain locally under `exploration/` and `experiments/`.
Their source cells and saved outputs can contain participant identities, clinical
annotations and individual results, so notebook files are excluded from Git.
An empty output cell is not proof that the notebook source is safe to publish.

Use the [package workflow](../README.md) for public reproducible examples.
In the full local research checkout, the retained first setup cell restores
legacy imports and repository-relative data paths. The private legacy source and
notebooks are not supplied by a fresh public checkout.
