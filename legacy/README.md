# Archived third-party source

`third_party/s4/` preserves the copied general sequence-modeling framework.
It is outside the installed scientific package. Original source and attribution
are retained. Generated binaries, build outputs and notebooks are excluded.
Its general benchmark workflows have not been revalidated for seizure modeling.

Patient-bound historical waveform code is retained only in the local research
workspace. Use [seizureprop](../src/seizureprop/README.md) for new applications.
